# Site do CCA Amigos da Vitória

Site institucional do **CCA Amigos da Vitória** (Centro para Crianças e Adolescentes), na Vila Aimoré, São Miguel Paulista, São Paulo – SP. Serviço em parceria com a Prefeitura de São Paulo (SMADS).

Endereço previsto: https://ccaamigosdavitoria.org.br/

## Estrutura

```
index.html              página única (HTML + CSS embutidos, sem JavaScript)
favicon.png             ícone do site
apple-touch-icon.png    ícone para iOS
img/                    imagens e logo
video/cca.mp4           vídeo de apresentação
```

## Como rodar localmente

Não há build nem dependências. Abra o `index.html` no navegador ou sirva a pasta:

```
python -m http.server 8000
```

Depois acesse http://localhost:8000.

## Observações

- As fontes (Oswald e Nunito) são carregadas do Google Fonts.
- As imagens do site foram geradas por inteligência artificial e não retratam crianças reais.
